# Social Bulk Downloader

Windows and Termux helpers around yt-dlp.

## Termux

```bash
git clone https://github.com/USERNAME/social-bulk-downloader.git
cd social-bulk-downloader
bash install.sh
python social_downloader.py
```

For details see `README_TERMUX.md`.

## Windows

Run `START.bat`.

Use only content you are authorized to download and follow applicable platform terms.
