# Social Bulk Downloader

Termux-ready bulk downloader powered by yt-dlp.

**Developer: Krishna**

Supports:
- Direct YouTube/Facebook/Instagram video or Reel URLs when supported by yt-dlp
- YouTube playlist/channel URLs supported by yt-dlp
- TXT files containing many URLs
- Resume/duplicate protection through yt-dlp's download archive

## Termux

```bash
git clone https://github.com/USERNAME/social-bulk-downloader.git
cd social-bulk-downloader
bash install.sh
python social_downloader.py
```

See `README_TERMUX.md` for details.

## Windows

`START.bat` is included for the desktop/Windows version, but the primary tested workflow in this package is Termux.
